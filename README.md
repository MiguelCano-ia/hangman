# 🕹️ Ahorcado - Juego Web

Este es un juego del Ahorcado desarrollado con **React**, **TypeScript**, **Tailwind CSS**. El objetivo es adivinar una palabra secreta antes de cometer 6 errores.

---

## 📸 Vista previa

👉 Puedes probar el juego aquí: https://hangman-eight-tau.vercel.app/

---

## 🚀 Tecnologías

- ⚛️ React 19
- 🎨 Tailwind CSS
- 🧠 TypeScript

---

## 🧩 Funcionalidades

- Entrada de letras por input y teclado virtual
- Dibujo del ahorcado en 6 pasos
- Letras correctas/incorrectas visibles
- Mensajes de victoria o derrota
- Soporte para caracteres especiales: ñ, áéíóú, ü
- Reinicio del juego
- Accesible y responsive

---

## ✅ Requisitos

- Node.js `>=18`

---

## 🔧 Instalación y uso local

1. Clona el repositorio:

   ```bash
   git clone https://github.com/MiguelCano-ia/hangman.git
   cd ahorcado
   ```

2. Instala las dependencias

   ```bash
     npm install
   ```

3. Inicia el servidor de desarrollo:

   ```bash
     npm run dev
   ```

4. Abre el puerto asignado por tu equipo
